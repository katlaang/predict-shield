# New physically measured adaptive-defense cohort (registered 2026-11-26)

**Classification: new exploratory physical cohort, NOT independent confirmation or evidence of AI decision superiority.**

This experiment runs automatically for a trusted same-repository PR that changes the physical pilot workflow. The runner builds a disposable four-JVM/Redpanda authorization laboratory, retrieves historical records, trains a fixed historical-only model before seeing the new physical outcomes, and generates an independent deterministic v3.1 plan with seed **20261128**. The selected group is the first test configuration lexicographically, without inspecting fault identity or action outcome.

Exactly one configuration group with three replays of four action arms (12 physical actions) is collected. This is not 12 independent configurations. Four physical streams are collected and reconciled. Measured security exposure, legitimate failed requests, actual budget breaches, and cost are reported for learned selector, monitor-only, resynchronization, and restart-if-permitted. The original pre-existing baseline definitions and metric weights are preserved. Any negative or inconclusive result must be retained. For a genuine prospective confirmation, a new disjoint multi-group study with preregistered hypotheses and uncertainty analysis is still necessary.

**Source and provenance control:** the PR commit, fixed plan seed, model digest, observed stream digest, GitHub run URL and raw experimental artifacts must be retained. A green workflow signifies execution succeeded, not AI superiority. This experiment cannot by itself establish U.S. critical-infrastructure effectiveness.

Safety: disposable locally controlled Docker infrastructure only; no external systems, unauthorized scanning, or production credentials. Mutating actions must respect registered lab authority. Preserve observed results even if safety limits are breached; never relabel breached actions as safe.

**AI decision superiority and critical-infrastructure effectiveness remain unproven.**
