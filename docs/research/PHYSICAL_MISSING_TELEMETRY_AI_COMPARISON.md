# Prospective missing-telemetry laboratory study (not 99.9% evidence)

This is a **new actual physical virtual-network collection** that takes the next step after the complete-telemetry AI/rule tie. All conditions are fixed before observing the held-out outcomes:

- Same five disposable Linux SNMPv3 agents and 28 preregistered, distinct Docker bridge configurations from the original measured topology protocol.
- **40% directional SNMP GET data missingness**, determined by SHA-256 of fixed research seed, topology, source and target *before attempting each probe*.
- **20 train topology configurations**, 8 heldout configurations. Each yields all 10 undirected endpoint pairs. The heldout sample is 80 pairs, which is far below the proposed 10,000-case 99.9% evidence gate.
- A new graph-aware logistic learner uses **only evidence available before the separate Docker network oracle**: direct observed probes, neighbor overlap, path connectivity, and missing telemetry indicators.
- The deterministic comparison uses observed direct management evidence and **full transitive closure of the remaining observed reachability graph**, not an artificially weak exact-match rule.
- Only **after** collecting all input probes does the separate host Docker API establish true segment co-membership. Labels represent software virtual-network reachability, not direct physical cables.
- The experiment must preserve negative, tied and incomplete results. No seed selection, post-hoc threshold change or repeated retraining on held-out configurations is permitted.

This study may find an AI advantage, a tie or a deficit. Even a positive advantage under this single lab's reconfigured membership cannot establish 99.9% discovery across 20 independently audited real ISP sites. No actual LLDP/BGP/gNMI topology discovery, external ISP field measurements, calibrated probability or defense automation is claimed.

GitHub Actions workflow `isp-physical-blindspot-study.yml` retains the actual model-v-rule confusion matrices, all heldout pairs, counts of skipped/missing probes, pre-oracle graph hashes, separate Docker truth hashes and trained coefficients. Any CI failure remains a failed trial and is not evidence of model superiority.
