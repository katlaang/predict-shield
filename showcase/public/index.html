A fix is only done when someone else can see it is done.

PREDICT-SHIELD ranks vulnerabilities, applies a response under policy, and then checks the result with evidence the response step cannot influence. Below are all 1,200 trials of its sealed verification test. In none of them did it report a fix that had not happened.

    Select any cell to replay that trial.

    Which response actually fixed the fault

    Each of the 100 fault configurations was run with all four responses, three times, and judged by an independent observer that reads every service directly.

    For lasting faults only a restart worked. For faults that clear on their own, any response ended fixed, so doing nothing was the cheapest choice under every cost assumption tested.

    Cost of each response, by how much a missed fix is assumed to cost

    Where a CVE ranks for exploitation

    A model trained on 2017 to 2023 data and tested once on every CVE published in 2024: the top 5% it flagged held 52% of the CVEs later confirmed as exploited. Look up any CVE published since 2025 to see its rank among 2025 CVEs.

    Highest-ranked CVEs published in 2026

    A low rank is not evidence that a CVE is safe. Ranks inform a human decision; they do not replace it.

    Detectors that fell short

    Every limit below was fixed before its test data was read, and each test ran once. These results are published with the same weight as the ones that worked.

    All results come from laboratory test beds and public datasets; PREDICT-SHIELD has not run in a production environment. Each figure links to its report in the public repository (Apache-2.0).
