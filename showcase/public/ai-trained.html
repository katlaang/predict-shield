What this demonstrates

  • Coefficients are fitted from labeled data using scikit-learn, not manually assigned scenario weights.
  • A threshold is selected on validation traffic before evaluating the independent test partition.
  • The browser reproduces learned model inference, including wrong predictions.
  • This model classifies recorded connections. It does not predict when a future attack will occur.
  • No firewall, router, service, real sensor or network is touched.
Research limitation: NSL-KDD is a legacy intrusion benchmark derived from older simulated traffic. Its labels are benchmark ground truth, not independently verified modern production observations. The displayed model scores are not calibrated probabilities of a real intrusion, and benchmark recall or false-alert rate must not be represented as real-network accuracy. The browser runs a real trained model, but this is not the field-pilot Zeek model or a deployment of PREDICT-SHIELD's entire defense pipeline.
